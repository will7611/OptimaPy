# 🚀 OptimaPy: Inteligencia Operativa para PyMEs

OptimaPy es una plataforma analítica desarrollada en Python que transforma datos crudos de ventas en decisiones estratégicas de inventario, precios y liquidez. Diseñado como solución para el Business Tech Challenge (Categoría: Empresa, marketing y mercados).

## 💡 Características Principales

1. **Alertas Predictivas de Inventario:** Utiliza Regresión Lineal para analizar la estacionalidad de productos y calcular el volumen exacto de compra necesario para el mes siguiente.
2. **Optimización de Precios:** Algoritmo dinámico que sugiere precios de venta finales para asegurar márgenes de ganancia netos (ej. 30%).
3. **Control de Flujo de Caja:** Cruza las proyecciones de venta contra los costos operativos fijos mensuales para emitir un diagnóstico de rentabilidad.
4. **Dashboard Interactivo:** Interfaz web intuitiva con gráficos avanzados y tablas de formato condicional (semáforos de riesgo).

## 🛠️ Stack Tecnológico

*   **Lenguaje:** Python 3.10+
*   **Machine Learning:** `scikit-learn`
*   **Procesamiento de Datos:** `pandas`, `numpy`
*   **Frontend Web:** `streamlit`
*   **Visualización Interactiva:** `plotly`
